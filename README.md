# Apple Video Subtitles — Loon

Fitness+ 中文 WebVTT 字幕及 Loon 单文件插件。中文字幕由原英文字幕翻译，保留字幕时间轴；原视频、音频和英文字幕不变。

## 首节课程

- Fitness+ / Kyle / 20 分钟全身力量训练
- 课程资源 ID：1686796699
- 字幕轨时长：20 分 47.562 秒
- 简体中文字幕：21 个 WebVTT 分片及一个 HLS 列表

安装地址在发布后补充。只需导入一个 Loon 插件，字幕从本仓库远程读取，插件不嵌入字幕正文。插件保留 Apple TV 现有 F1、DTS 和电影规则，并为上述课程增加中文轨。

使用需有对应课程的 Apple Fitness+ 访问权限，并开启 Loon MITM 和脚本功能、完全信任证书。本课的字幕入口使用 Loon Rewrite V2；须使用支持该语法的版本。中文轨加载及拖动同步仍需在手机上实机验收。
